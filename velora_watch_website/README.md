# VELORA Watch Storefront

A responsive front-end demo website for a watch brand, built with plain HTML, CSS and JavaScript.

## How to run
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in your browser. For a smoother development workflow, install the Live Server extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

## Customize
- Change the brand name, copy, watch names and prices in `index.html`.
- Update colors, spacing and typography in `style.css`.
- Update filtering and demo interactions in `script.js`.
- Product photos are loaded from Unsplash and require an internet connection.
- Prices are sample prices in Nigerian naira.
- Cart notifications and newsletter signup are front-end demonstrations only. No payment, order processing, email storage or backend is connected.

## Files
- `index.html` — website structure and product content
- `style.css` — responsive design
- `script.js` — mobile menu, category filters and demo interactions
